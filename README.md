# Tom Chiyaka (TJ) Portfolio

Open `index.html` in any modern browser.

## Replace these placeholders
1. Hero action photo
2. Gallery photos
3. Main highlight video
4. Full-match / extended video
5. Finishing / attacking clips
6. Contact name, email and WhatsApp
7. Season statistics
8. Exact Surge FC years
9. Nationality / passport information if appropriate
10. Coach references

## Media setup
For local images, place files in `assets/` and replace the placeholder blocks with `<img src="assets/your-photo.jpg" alt="...">`.
For video, use YouTube/Vimeo embeds or a local `<video controls>` element.
